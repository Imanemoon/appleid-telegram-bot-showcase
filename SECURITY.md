# Security Policy

## Scope

This repository is a **public showcase** containing documentation, diagrams, and
aggregate metrics only. It contains no production source code, no secrets, and
no operational configuration.

## Reporting a vulnerability

- If you find a security issue **in this showcase repository** (for example,
  inadvertently exposed information), please use GitHub's
  [private vulnerability reporting](https://github.com/Imanemoon/appleid-telegram-bot-showcase/security/advisories/new)
  rather than opening a public issue.
- If you find a security issue **in the Telegram bot service itself**, please
  report it privately to the operator through the bot's support conversation —
  do not include sensitive details in public channels.

## Content policy

- No tokens, credentials, environment files, or encrypted secret material are
  published here.
- No private infrastructure details (hosts, endpoints, networking) are
  published here.
- No user data of any kind is published here.
- If sensitive information is ever discovered in this repository, it will be
  removed promptly — and if any credential were ever exposed, rotation would be
  treated as required rather than optional.
